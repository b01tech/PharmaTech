# PharmaTech

Esse é um projeto de ERP de farmácia e tem como base o projeto `pharmacore` desenvolvido na **Mentoria 360 da Formacao.dev**.

- O projeto original foi desenvolvido com TypeScript, NEST e NEXTJS.
- Essa é uma adaptação para fins de estudo em .NET10 e Angular 21.
- Principais alterações estão documentadas em [docs/mudancas.md](docs/mudancas.md).

## Projeto em desenvolvimento

> O projeto está em desenvolvimento.
> Apenas módulo de produtos está implementado.

## Como executar o projeto

1. Clonar o repositório

```bash
git clone https://github.com/b01tech/PharmaTech.git
```

2. Subir o banco de dados

```bash
cd PharmaTech/apps/backend
docker-compose up -d
```

3. Buildar e executar o backend da aplicação

```bash
cd apps/backend/PharmaTech.Api
dotnet build
dotnet run
```

4. Instalar as dependências do frontend

```bash
cd apps/frontend
npm install
```

5. Executar o frontend da aplicação

```bash
npm run start
```

A aplicação ficará disponível em `http://localhost:4200`.
E o backend em `http://localhost:5001`.

## Documentação

A documentação da API está disponível em `http://localhost:5001/docs` através do Swagger.
